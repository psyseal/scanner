# Seguridad · Security

Si encuentras una vulnerabilidad en el escáner, la limpieza o el sello, escríbenos a hola@psyseal.com con el asunto «Seguridad». Por favor no la publiques en un issue, para poder corregirla antes de que se haga pública.

If you find a vulnerability in the scanner, the cleanup or the seal, email hola@psyseal.com with the subject "Security". Please do not open a public issue, so we can fix it before it becomes public.
